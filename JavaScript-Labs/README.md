## 4. Nội dung các bài Lab

### Lab 08 – JavaScript 1: Language Foundations
Gồm 11 Exercise (8.1–8.11).

Nội dung: nhúng JavaScript vào HTML, sử dụng
JavaScript bên ngoài, Browser Console, String,
Date, Math, Array, Function và Object.

### Lab 09 – JavaScript 2: DOM and Events
Gồm 8 Exercise (9.1–9.8).

Nội dung: lựa chọn và chỉnh sửa DOM, quan hệ
giữa các nút DOM, xử lý sự kiện chuột, sự kiện load,
debugging và kiểm tra dữ liệu biểu mẫu.

### Lab 10 – JavaScript 3: jQuery
Gồm 10 Exercise (10.1–10.10).

Nội dung: jQuery Selectors, Events, thao tác DOM,
Animation, GET Requests và jqXHR Handling.
